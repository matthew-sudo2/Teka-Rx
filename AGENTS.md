# TekaRx contributor guidance

- Keep data and secrets out of version control.
- Treat model outputs as research decision-support signals, never diagnoses.
- Preserve data provenance and document dataset licenses.
- Run `pytest` and `ruff check .` before submitting changes.

## antislop
